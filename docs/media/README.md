# 功能说明图

![人类调度功能一览](humancall-feature-overview.png)

基于 v0.1.25 实际页面制作，主界面上叠加任务清单、消息提醒、语音回复、瞬笺、个人资料和日历；日历展示月视图及选中日期右侧的当天清单。

使用内置 imagegen 生成。输入为已有六模块成图，以及独立界面测试生成的日历截图；文案、昵称、任务均为演示内容。说明图用于介绍功能，界面细节以实际应用为准。完整提示词见 [生成记录](feature-overview-prompt.md)。

只提交定稿，初稿、原始测试截图和设计中间文件保留在已忽略的 `design/`、`work/` 目录。
