# 日历 · 使用与本地开发

日历随 v0.1.25 桌面版发布。需要独立体验或调试时，运行 `npm run dev:calendar` 打开“日历开发版（独立数据）”。

首次打开时，从已有本机数据建立独立副本，保存在项目 `work/calendar-dev-profile`。副本清除模型、语音密钥，关闭通知和自动语音；之后的编辑仅写入副本，不影响正式数据。再次打开保留已有副本。

日历入口位于任务与提醒和瞬笺之间。月视图按周一到周日排列，支持切换月份、月份跳转和返回今天；每格展示当天前两项及剩余数量。点击日期，从右侧打开当天清单，可筛选、搜索，直接添加、编辑、完成、调整状态或二次确认删除任务，也能管理一次性、每天和每周提醒。重复提醒的编辑、停用或删除会作用于该条提醒及后续安排。

新任务可只填写“安排日期”，不强行补开始时刻。填写具体开始时间时，以开始时间为准；截止时间不能早于安排日期。任务与原有清单共用记录，未定日期的工作放在“未排期”；未来的全天任务不会提前执行或被后台催办。跨天任务和跨午夜会议按实际覆盖日期展示，总任务不重复计数。

重复提醒向未来按实际频率展开，过去仅展示真实触发记录。跨午夜迟到的提醒以原定日期归档，不在实际触发日重复一条。日历是当前安排视图，修改事项日期会移动其安排，不作为不可变的操作日志。

瞬笺“所有人”的头像与昵称改为我的资料；点击头像打开我的资料。筛选伙伴时，仍显示对应伙伴的信息。

验证：

```powershell
npm run check
npm test
npm run test:calendar-ui
npm run test:task-settings
npm run test:chat-ui
```

界面检查使用临时数据，不请求外部模型，覆盖任务／提醒管理、保存重载、头像归属、主题和窄窗口。预览在 `work/calendar-previews`。
