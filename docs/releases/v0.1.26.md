# 人类调度 v0.1.26

新增生成模型 Token 使用统计，减少 Agent 的重复上下文，并修复编辑任务表单对齐。

## Token 使用

- 在“我的统计”和“历史明细”查看 Token 使用，覆盖日常回复、任务调度、主动提醒、瞬笺、表情筛选、配图筛选和模型连接测试；不计语音模型。
- 按一次任务汇总多轮调用与重试，可展开查看每次调用的模型、输入、输出和总量，并按日期、人物和关键词筛选。
- 统计随本机数据保存、迁移和备份；未返回用量时明确标注，不将其误记为零。仅从本版本开始记录，历史用量无法补算。

## Agent 优化

- 查询结果只发送任务操作所需字段；修改后只返回发生变化的任务和提醒，保留自动切换的下一项及总任务状态变化。
- 精简固定提示和日期上下文，为过长历史设置总量上限，保留消息日期依据与完整的本轮请求。
- 支持在执行动作时同时制定计划；普通文字回复可直接结束，减少仅为收尾而增加的模型调用。
- 保留任务校验、删除确认、澄清追问与并发修改保护。实际 Token 用量以服务商返回为准。

## 界面修复

- 修复编辑任务时“任务状态”被日期说明撑高、与相邻控件错位的问题，兼容桌面和窄屏布局。

提供 Windows x64 安装程序、macOS 通用 DMG（Apple 芯片／Intel，macOS 11 及以上）及各自 SHA-256 校验文件。
