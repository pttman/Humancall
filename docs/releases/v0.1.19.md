# 人类调度 v0.1.19

这轮更新重做了淡彩涂抹风格界面，修复消息滚动与 Windows 提醒定位，并调整了任务记录、Agent 重试和瞬笺配图。

- 聊天位于最新位置时自动滚到底部；看历史时保持位置并提示新回复。
- 设置、资料、清单与聊天配色统一；移除侧栏“今日安排”卡片。
- 陆野更名为枫言；片刻更名为瞬笺，更新 Banner 和底部标语。
- 所有人的默认头像恢复原版，保留两位伙伴的三组新头像，以及“我”的三个新头像作为可选项。
- 提醒选项由模型按需生成，普通告知不强制带选项；聊天减少套话与总结腔。
- 未给时间的待办先记录再追问；每轮刷新当前时间，避免使用过期安排。
- Agent 失败后自动重试两次，成功后只提交一次。
- 瞬笺改用在线图库 API 搜索匹配图片，后台下载、缓存并保留来源，不再使用内置摄影图作为新配图。
- 同步更新 Windows x64 安装程序和 macOS 通用 DMG，附 SHA-256 校验文件。

完整改动见仓库 CHANGELOG.md。

## 安装文件

- Windows：`Humancall-Setup-0.1.19-x64.exe`
- macOS：`Humancall-0.1.19-mac-universal.dmg`（Apple 芯片与 Intel）

macOS 包仍使用本地临时签名，尚未进行 Apple Developer ID 签名或公证。首次打开若被系统拦截，请按 README 中的说明在系统设置中允许打开。桌面端需保持运行，才能按时发送提醒。
