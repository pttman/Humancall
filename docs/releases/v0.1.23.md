# 人类调度 v0.1.23

修复跨天对话的日期理解，补全提醒记录和关闭窗口后的回复通知。

- 历史“今天／明天／明早”绑定原消息的发送日期，昨天约定明天处理的任务按今天承接，不会被重新顺延一天。
- 查询真实任务后处理已有安排，普通进度汇报不代表允许改截止或静默；不再凭空沿用 9:30 等时刻。
- 主动督促、固定提醒、休息结束通知均记录到对话后再弹出，保留事件上下文并去重。
- 发送消息后关闭或最小化主窗口，回复完成后补发气泡；窗口可见时不额外弹出，气泡回复也不会重复提示。通知开关和静默设置仍有效。
- Windows x64 和 macOS 通用包同步更新，附 SHA-256 校验文件。

完整改动见 CHANGELOG.md。macOS 仍使用本地临时签名，尚未进行 Apple Developer ID 签名或公证，首次打开方式见 README。
