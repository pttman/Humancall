# 人类调度 v0.1.24

新增可配置的豆包语音输出，改善表情重复与模型连接测试，Windows 和 macOS 同步更新。

## 语音输出

- 设置中独立配置语音 API Key、人物音色、语速和音量；大模型与语音分别测试，支持保存前试听。
- 支持自动朗读新回复和提醒，也可点击发送者名字旁的声音图标手动播放，再次点击停止。默认关闭语音服务。
- 知序默认“灵动欣欣 2.0”，枫言默认“小天”，各自保留其他备选和自定义音色 ID。
- 每段音频前加入 1 秒静音，给设备启动与音量渐强留出缓冲，完整保留原始语音；自动朗读时不叠加弹窗提示音。
- 语音失败不影响文字回复和任务保存。Key 只保存在本机，不发送给聊天模型，也不进入导出备份；语音费用与音色权限以服务商为准。

## 连接测试与重试

- 移除设置底部总测试按钮，改为“大模型”和“语音”分区测试。
- 大模型连接测试正常只发一次最小请求，不运行完整 Agent、不读取聊天或任务、不保存草稿；仅在工具参数不兼容时额外探测一次纯文本连接。
- 增加 20 秒完整测试超时、等待计时、取消按钮与实际耗时／请求次数；测试期间避让对话及后台模型请求。
- 区分 503 服务繁忙、429 限流和认证／配置错误。临时 HTTP 故障最多重试两次，加入约 2 秒、4 秒退避及少量随机间隔，遵守 Retry-After；明确的永久错误不重复请求。
- 失败草稿不提交，等待期间任务或设置变化会停止重试。

## 表情与瞬笺

- 检索时打散整个匹配池，由模型筛出符合当前语境的表情，再随机抽取一张；静态、动态都可参与，保留近期去重。
- 瞬笺选择“所有人”时隐藏右上方人物卡，筛选个人时显示对应头像。

提供 Windows x64 安装程序和 macOS 通用 DMG（Apple 芯片／Intel，macOS 11 及以上），附各自 SHA-256 校验文件。

macOS 使用本地临时签名，尚未进行 Apple Developer ID 签名或公证；首次打开方式见 README。完整改动与语音配置方法见 CHANGELOG.md、docs/voice-development.md。
