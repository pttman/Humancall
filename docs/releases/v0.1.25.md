# 人类调度 v0.1.25

新增日历页面，改善等待回复时的交互，并让桌面窗口融入现有界面。Windows 与 macOS 同步更新。

## 交互与提醒

- 主动督促默认间隔改为 30 分钟，移除没有参与调度的“默认检查间隔”。旧版默认 10 分钟自动迁移，自定义间隔保留。
- Agent 回复期间只暂停发送，可以继续输入草稿、切换伙伴和页面、查看历史、编辑清单、设置与个人资料。
- 不同伙伴分别保留输入草稿，延迟回复归原对话；完成时不抢走正在编辑的焦点，后台完成回复仍按原配置提醒。
- 手动编辑安排后保留新内容，不提交过期的 Agent 操作；并发保存合并刚创建的事项。清空对话会取消该对话的待完成请求，旧消息不会重新出现。

## 日历与瞬笺

- 任务与提醒、瞬笺之间新增日历入口，支持切换月份、返回今天、日期预览和未排期清单。
- 点击日期从右侧展开当天清单，可新增、编辑、完成、调整状态或删除任务，以及管理一次性、每天和每周提醒；与原有清单共用数据。
- 支持仅指定安排日期的全天任务，未来事项不会提前开工或被催办；跨天事项按日期显示，重复提醒的过去日期仅展示实际触发记录。
- 三种主题和窄窗口均适配。瞬笺选择“所有人”时使用我的头像与昵称，点击打开我的资料；筛选伙伴时显示对应伙伴。

## 桌面外观

- Windows 移除系统标题栏，顶部集成最小化、最大化／还原和关闭按钮，保留拖动、窗口缩放与关闭到托盘。
- macOS 隐藏标题文字栏，保留系统交通灯按钮与 Dock 恢复窗口。

提供 Windows x64 安装程序、macOS 通用 DMG（Apple 芯片／Intel，macOS 11 及以上）及各自 SHA-256 校验文件。macOS 首次打开方式见 README。
