# 人类调度 v0.1.28

通过手机微信 ClawBot 和电脑上的人类调度对话，微信与桌面共用任务和对应伙伴的聊天记录。

## 微信接入

- 打开「设置 → 微信接入」，选择知序或枫言，点击「扫码绑定微信」，用手机微信扫码并确认授权；支持手机验证码。
- 在手机 ClawBot 会话发送文字或微信已转写的语音，添加待办、查询任务、汇报进度、继续聊天，沿用已保存的模型配置和人物资料。
- 支持查看连接状态、切换伙伴、暂停接收、恢复连接和解除绑定；重启应用后恢复已启用的绑定。
- 本地程序主动连接微信服务，无需公网 IP、域名或内网穿透。电脑需开机、联网，并保持人类调度运行。

## 消息与数据

- 桌面自动同步微信新消息和任务，保留输入草稿及当前伙伴；并发保存合并新增内容，冲突时保留最新安排。
- 消息先落盘再确认游标，按消息 ID 去重；断网自动重连，发送失败只重试回复，不重复执行任务。执行期间异常退出的消息不会自动重跑，请先核实结果再重发。
- 微信凭证独立保存在本机，不包含在备份、状态接口或安装包中。

## 使用范围

产品设置内置完整接入说明。首次使用需在手机微信「我 → 设置 → 插件」开启 ClawBot；没有入口时请更新微信并确认账号可用范围。

当前支持扫码绑定者的一对一文字和已转写语音，图片、文件、视频与群聊暂不处理。删除和清空任务请在桌面窗口操作；定时提醒仍在桌面显示，本版不向微信主动推送提醒。**PC 微信是否显示并支持 ClawBot 会话需实测**，电脑可继续使用人类调度自己的聊天窗口。

协议、消息恢复、伙伴隔离、并发保护与真实界面测试已通过；真实微信服务可获取二维码，个人账号授权及最终收发需安装后扫码验证。

提供 Windows x64 安装程序、macOS 通用 DMG 和 SHA-256 校验文件。
