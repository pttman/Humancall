# 人类调度 v0.1.27

恢复长时间关闭应用后沉睡的过期任务提醒，并修复 Windows 任务栏图标。

## 启动恢复

- 启动时扫描过期且未完成的任务，包括丢失检查计划和仅有历史安排的任务；不重新激活已完成、已取消的任务或总任务。
- 通过本地汇总消息和气泡提示待重新确认的安排，不依赖模型决定是否提醒。
- 为过期任务恢复后续逐项检查，按提醒间隔错开，合并重复计划；保留仍有效的未来检查。原定开始、截止时间保持不变，新的具体安排可在聊天中确认。
- 遵守通知开关、静默时间和工作时段；仍在延期、安排在未来或正在进行的事项不重复催办。
- 快速重启与页面重载不会重复入账；通知发送失败可重试，用户已重新安排的任务不会收到旧的启动提示。

## Windows 图标

- 补齐任务栏图标、重启命令和应用名称，最小化及恢复时使用应用图标。
- 开发版使用独立应用标识及带应用图标的快捷方式，避免继承 Electron 或旧安装版的任务栏分组。

新增过期任务恢复、真实启动气泡、通知重试及任务栏图标回归检查。提供 Windows x64 安装程序、macOS 通用 DMG 及 SHA-256 校验文件。
