# 人类调度 v0.1.29

应用里的新回复和提醒会主动同步到手机微信 ClawBot，无需每次先由你发消息。

## 微信主动推送

- 监听所有伙伴新增的聊天回复、定时提醒、主动消息和瞬笺，自动推送并标注伙伴名称。
- 表情以文字说明同步，瞬笺配图暂不转发。
- 独立的持久发送队列，不受微信接收长轮询阻塞；发送失败自动重试，长消息分段发送，重启后继续发送待同步内容。
- 按消息去重，不重复转发微信本身的回复，也不补发历史记录或导入备份。
- 设置显示会话是否就绪和待同步数量；暂停连接时停止收发与采集新输出，恢复后继续处理已有队列。

## 升级后使用

更新并重新启动应用后，在手机 ClawBot 会话发一句话，建立主动推送会话。之后应用有新输出就会自动同步；若微信会话过期，再发一句话刷新。

电脑需开机、联网，并保持人类调度运行。微信发来的消息继续由设置中选择的伙伴处理。微信凭证、会话上下文和发送队列仅保存在本机，不随数据备份导出。删除与清空任务仍需在桌面窗口操作。

142 项后端测试及模拟微信界面测试通过，覆盖主动提醒、伙伴输出、重试恢复与备份隔离；真实账号推送需安装后扫码验证。

提供 Windows x64 安装程序、macOS 通用 DMG 和 SHA-256 校验文件。
