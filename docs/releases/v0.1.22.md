# 人类调度 v0.1.22

修复瞬笺日期范围与发布者显示错误。

- 只根据本机当天的聊天、任务变化生成当天动态，不再带入昨天或未来的素材。
- 当天没有新素材时不补发；发布额度按自然日计算，跨午夜的文案或选图候选自动丢弃。
- “今天”时间线排除昨天与未来动态，跨日自动刷新；历史仍可从“全部”查看。
- 所有人时间线使用统一标题，单条动态与聊天通知按实际发布者显示姓名、头像和资料链接，知序的动态不会随当前会话显示成枫言。
- Windows x64 与 macOS 通用安装包同步更新，包含 SHA-256 校验文件。

完整改动见仓库 CHANGELOG.md。macOS 仍为本地临时签名，未进行 Apple Developer ID 签名或公证，首次打开方式见 README。
