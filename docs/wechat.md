# 微信接入

在「设置 → 微信接入」中扫码绑定手机微信 ClawBot，让微信消息交给电脑上的人类调度处理。接入通过腾讯 iLink HTTPS 长轮询收发消息，电脑主动连接微信服务，无需公网 IP、域名或内网穿透，也无需启动 PC 微信。手机与电脑可以使用不同网络。

## 开始使用

1. 保存人类调度的模型配置，确认桌面聊天正常。未配置模型时只能使用现有本地规则。
2. 手机微信进入「我 → 设置 → 插件」，开启 ClawBot。没有入口时，先更新微信并确认账号已开放此功能。
3. 打开人类调度「设置 → 微信接入」，选择知序或枫言，点击「扫码绑定微信」。用手机微信扫描二维码并确认授权；若手机显示数字验证码，在产品内填写并提交。二维码过期后重新获取。
4. 显示「已连接」后，在手机 ClawBot 会话发送一句文字，确认收到回复。比如「帮我记下明天下午整理报告」，随后查看桌面聊天与任务。

微信与所选伙伴共享聊天记录、人物资料、任务、提醒和已保存的模型配置。桌面切换伙伴不会改变微信伙伴；在微信接入区域修改伙伴立即生效，已接收的消息仍归原伙伴。设置中的扫码、暂停、启用、切换伙伴、解除绑定立即生效，无需再点击「保存设置」。

## 使用范围

- 支持扫码绑定者的一对一文字消息，以及微信已转写为文字的语音。其他发送者及群消息不会交给本地模型。
- 图片、未转写语音、文件、视频暂不处理，会收到文字说明；只含文字的消息正常处理。
- 删除与清空任务保留桌面确认流程，请在桌面窗口操作。微信端不会根据一条远程确认消息直接执行删除。
- 本版不向微信主动推送定时提醒。微信可以创建和查询提醒，实际通知仍由桌面运行时显示。
- **PC 微信聊天支持需实测**：手机扫码绑定，不代表 PC 微信一定支持 ClawBot 会话。是否显示、能否发送消息取决于微信客户端。电脑可继续使用人类调度自身的聊天窗口。

## 运行与恢复

电脑需要开机、联网，人类调度需要持续运行。退出、断网或休眠期间不能实时处理消息，恢复运行后继续接收。启动时自动恢复本机已启用的绑定；「暂停接收」保留凭证，可再次启用；「解除绑定」停止处理并删除本机凭证及待发送回复，任务和聊天记录保留。必要时也到手机 ClawBot 中解除旧连接。

网络中断自动退避重连；凭证失效会提示重新绑定。消息先保存到本地收件箱再更新接收游标，按消息 ID 去重。回复发送失败保留待发送内容，仅重试发送，不重复调用模型执行任务。异常退出时执行中的消息标记为中断，不自动重跑；先核实桌面任务与聊天中的实际结果，再从微信重新发送。该机制不承诺外部消息发送的严格恰好一次。

桌面与微信同时修改任务、设置或同一对话时，冲突的一轮停止提交并提示重发。后台轮询同步微信新增的聊天和任务，保留桌面的输入草稿、当前伙伴及设置表单。

## 数据与隐私

微信消息经腾讯微信服务传输；模型处理沿用本产品的服务商设置，相关聊天和任务上下文发送至该模型服务商。微信凭证与接收游标保存在独立的本机 `wechat-connection.json`，不写入聊天设置，不通过状态接口返回，不包含在导出备份或安装包中。文件还可能包含尚未处理的消息、待发送回复和中断记录，请勿分享。

桌面模式连接文件位于应用用户目录（与 `data-directory.txt` 同目录）；网页开发模式位于 `backend/`。更改任务数据保存位置时，连接文件仍在原应用配置目录。导入数据备份不会替换微信绑定。

## 开发与验证

`backend/wechat-client.cjs` 负责腾讯协议与服务地址检查，`wechat-service.cjs` 管理绑定、重连、收件箱与回复队列，`wechat-conversation.cjs` 复用现有聊天服务。独立 HTTP 服务和 Electron 均通过同一服务接入。前端入口为 `frontend/wechat-ui.js`。

参考腾讯公开的 [协议文档](https://github.com/Tencent/openclaw-weixin/blob/main/docs/protocol.md) 与 [2.4.10 客户端实现](https://github.com/Tencent/openclaw-weixin/tree/v2.4.10)。本产品直接实现消息适配，不要求用户安装 OpenClaw。上游协议和账号可用范围可能变化，扫码后以实际连接状态为准。

检查使用模拟微信与模拟模型，临时目录保存测试数据，不登录真实微信，不发送真实消息、不消耗用户模型额度：

```powershell
npm run check
npm test
npm run test:wechat-ui
```
